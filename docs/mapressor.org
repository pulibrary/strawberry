* How to Create a METS/ALTO Object
** Major Sections of a METS Object
The METS schema defines seven major sections in a METS document, but
in practice we will be concerned with only four: the METS Header, the
Descriptive Metadata section, the File Section, and the Structural
Map. (Please see the LOC's [[https://www.loc.gov/standards/mets/METSOverview.v3_en.html][Overview and Tutorial]] for a good
introduction to METS.)
